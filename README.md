# Drawora

A free, open-source, browser-based collaborative whiteboard.

## Usage

Open `index.html` in a modern browser.

### Tools

| Tool   | Shortcut |
| ------ | -------- |
| Select | `V`      |
| Pen    | `P`      |
| Eraser | `E`      |

Shape tools: line, rectangle, rounded rectangle, ellipse, triangle, and arrow.

### Editing

| Action        | Shortcut              |
| ------------- | --------------------- |
| Undo          | `Ctrl+Z`              |
| Redo          | `Ctrl+Y` or `Ctrl+Shift+Z` |
| Delete        | `Delete` / `Backspace` |
| Duplicate     | `Ctrl+D`              |
| Copy / Paste  | `Ctrl+C` / `Ctrl+V`   |
| Deselect      | `Esc`                 |

Select an object to move, resize, or rotate it. Shift-click adds or removes objects from the selection. Multi-selection supports move, delete, duplicate, and copy/paste. Resize and rotation handles appear when a single object is selected.

Use **Stroke** and **Fill** to set outline and fill colors. With an object selected, color and size changes apply to that object.
